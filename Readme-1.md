Beef Player

界面

程序分为界面、控制、数据传输三部分，

界面包括菜单，主界面。

菜单包含文件 控制 关于三个主菜单

文件菜单包含 打开文件 关闭文件 退出程序 

控制菜单包含 上/下一首 暂停/播放 声道选择

声道选择是另一个界面，可以打开或关闭一个或多个声道

关于也是弹出对话框，对本程序的描述以及版本号
